# 💰 Student Expense Tracker

A simple expense-tracking web application built using Python. This project helps students record their daily expenses, monitor their monthly budget, and understand their spending habits through interactive charts.

## 🚀 Live Demo

[Try the Student Expense Tracker](https://sai-student-expense-tracker.streamlit.app/)

## ✨ Features

- Add and manage daily expenses
- Edit or delete transactions
- Categorize expenses such as Food, Transport, Education, Shopping, Bills and other.
- Set a monthly budget and track the remaining balance
- View total expenses, transaction count, and average expense
- Visualize spending by category using a pie chart
- Compare spending across months using a bar chart
- Download monthly transactions as a CSV file

## 🛠️ Technologies Used

- **Python** — application logic
- **Streamlit** — web application interface
- **SQLite** — expense data storage
- **Pandas** — data processing and analysis
- **Plotly** — interactive visualizations

## 💻 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/SaiChowdaryDev/student-expense-tracker.git
   ```

2. Move into the project folder:

   ```bash
   cd student-expense-tracker
   ```

3. Install the required packages:

   ```bash
   pip install -r requirements.txt
   ```

4. Start the application:

   ```bash
   python -m streamlit run app.py
   ```

5. Open the local URL displayed in your terminal.
